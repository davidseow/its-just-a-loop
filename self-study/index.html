It's Just a Loop

Your AI agent isn't magic. It's a brain in a jar, a kettle, and a while-loop with good manners.

Press → or Space to advance.

The only job we'll do today

"Make me a cup of tea."

On every slide we ask for the same thing, and add one piece to the machine. Keep an eye on the mug in the top corner.

The spec

  1. Boil the kettle.
  2. Teabag in the mug.
  3. Pour. Steep three to four minutes.
  4. Splash of milk. No sugar.
Stage 1 · The bare model

A very clever brain in a jar.

A language model reads text and writes text. That's all it does. No hands, no kettle, no clock.

reply = model("Make me a cup of tea")
show(reply)
The model replies

"Tea (Camellia sinensis) has been enjoyed for thousands of years. The perfect cup begins with freshly drawn water, brought to a rolling boil…"

[ 412 more words ]

A lovely essay. Zero tea.

What's inside the jar

It guesses the next word. Then it does it again.

At every step it scores the likely next pieces of text and picks one. It's autocomplete that has read most of the library: brilliant with words, useless with kettles.

Illustrative numbers. A real model scores tens of thousands of options at every step.

Stage 2 · Give it a label

Tell it who it is.

A system prompt is a note stuck on the jar before the chat starts. It sets the role, the tone and the rules. Meet Hobbs.

reply = model(
    system = "You are Hobbs, a helpful butler.",
    user   = "Make me a cup of tea"
)
Hobbs replies

"Certainly, sir. Permit me to describe a most splendid cup of tea…"

Better manners. Same amount of tea.

Stage 3 · Give it hands

It can't hold a kettle. It can ask for one.

We give the model a menu of tools. It replies with a request. Our own code, the harness, does the actual work and reports back.

tools = [boil_kettle, add_teabag, pour, wait, add_milk]
reply = model(messages, tools)     # Hobbs: "CALL boil_kettle()"
if reply.wants_tool:
    result = run(reply.tool)       # the harness does this, not the model

Then it stops. One request, one action, job abandoned. Hobbs boiled the kettle and went home.

Stage 4 · The big idea

Put it in a loop.

Ask. Act. Show the model what happened. Ask again. Stop when the model says it's finished.

messages = ["Make me a cup of tea"]
while True:
    reply = model(messages, tools)
    if reply.is_done:
        break
    result = run(reply.tool)
    messages.add(reply, result)
show(reply)

That's it. That's the harness.

Stage 5 · Brakes

A loop with no brakes.

The first wave of hobby agents (around 2023) looped freely. Some got the job done. Some wandered off with great confidence.

Stage 6 · A notebook

The jar only holds so much.

Every lap, the model re-reads the whole conversation. That space is the context window, and it fills up. When it's full, the oldest things fall out. Things like "no sugar".

Stage 7 · A bouncer

Some requests need a human.

The harness checks every request before running it. Safe ones go straight through. Risky ones wait for a yes.

Permission needed

Hobbs wants to run
descale_kettle(with="bleach")

if reply.tool.is_risky:
    if not ask_human("Allow " + reply.tool.name + "?"):
        result = "Refused by human"
        continue
result = run(reply.tool)

The model can ask for anything. The harness decides what actually happens. That's why a lot of safety lives here, not only in the brain.

Stage 8 · Today

Same loop. Bigger kitchen.

Today's agents read files, run code, browse the web and work for hours. Some send helpers off to do parts of the job, each running its own loop.

Take this home

The model is the brain. The harness is everything else.

messages = [instructions, request]                # label
steps = 0
while steps < MAX_STEPS:                           # loop + brakes
    reply = model(messages, tools)                 # brain
    if reply.is_done:
        return reply
    if reply.tool.is_risky and not ask_human(reply.tool):
        result = "Refused by human"                # bouncer
    else:
        result = run(reply.tool)                   # hands
    messages = tidy(messages + [reply, result])    # notebook
    steps += 1

A lot of recent progress in AI agents is in the kitchen, not just the brain. Next time someone says "agent", picture Hobbs and the loop.
