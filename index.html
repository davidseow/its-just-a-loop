How it remembers (it doesn't)

It has the memory of a goldfish.

Every call

starts blank. The model remembers nothing from last time.

So the harness

re-sends the whole chat, every time, in small pieces called tokens.

history.add(reply)

Like re-reading the whole book before writing each new sentence. Every. Single. Time.

How it really works · The tool menu

A tool is a note for a babysitter.

Each tool has a name, a short description and what it needs. Hobbs reads the menu and picks.

look_around()

Describe what is in the room. Use this first if you're not sure.

Needs: nothing

feed(name, pinches)

Give food to someone or something. 1 to 3 pinches. More is not better.

Needs: who, and how many pinches

ask_human(question)

Ask the owner one question. They are at their mother's. Keep it short.

Needs: one question

A vague description gets vague behaviour. Write it as if the babysitter has never met Gary.

Stage 4 · The big idea

Put it in a loop.

Think

Act

Look

Repeat

messages = ["Take care of Gary"]
while True:                                  # the loop
    reply = model(messages, tools)           # Hobbs thinks
    if reply.is_done:                        # Hobbs says "finished"
        break
    result = run(reply.tool)                 # the harness acts
    messages.add(reply, result)              # Hobbs sees what happened

Ask. Act. Show Hobbs what happened. Ask again. Stop when Hobbs says he's finished.

Stage 4 · Why asking works

Asking is just another tool.

A bare model

Must answer right now, in one go. It can't wait for you. So it guesses.

Result: Gary under the patio.

A model in a loop

Can ask, wait and carry on. Your answer arrives as the result of a tool.

Result: Gary correctly fed.

In a chat, you are the loop. In an agent, the harness is.

That's why "ask if unclear" works: the loop gives the answer somewhere to go.

How it really works · Why loops go wrong

Incident reports from Gary's house.

1 · Stuck on repeat

"Tried to open the fish food 47 times. Lid: still on."

Fix: brakes, plus "after 3 fails, try something else".

2 · Imaginary tools

"Called feed_by_drone(). There is no drone."

Fix: the harness refuses unknown tools and lists the real ones.

3 · Early victory

"Reported: Gary is fine. Had not looked at Gary."

Fix: check the result before saying "done".

4 · Misreading

"Read 'Out of fish food' as 'Out of fish'. Panicked."

Fix: clear, simple results from every tool.

Take this home

The whole harness, in twelve lines.

messages = [label, "Take care of Gary"]           # label
laps = 0
while laps < MAX_LAPS:                            # loop + brakes
    reply = model(messages, tools)                # brain
    if reply.is_done:
        return reply
    if reply.tool.is_risky and not ask_human(reply.tool):
        result = "Refused by human"               # bouncer
    else:
        result = run(reply.tool)                  # hands
    messages = tidy(messages + [reply, result])   # notebook
    laps += 1

Three things to remember

If you forget everything else…

1

The model is the brain. The harness is everything else.

A lot of recent progress in agents is in the harness, not just the brain.

2

Asking is a tool.

"Ask if unclear" works best when there's a loop to carry the answer back.

3

When an agent misbehaves, check the harness.

Brakes, notebook, bouncer. That's usually where the fix is.
