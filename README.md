# It's Just a Loop

How an AI learned to take care of Gary. A talk about AI harnesses, and a sequel to [Ask If Unclear](https://davidseow.github.io/a-case-for-llm-clarification/).

- **Presenter deck** (`index.html`): 30 slides, about 45 minutes with Q&A. Use the arrow keys, Space or a click to move on. Press F for full screen.
- **Self-study version** (`self-study/`): a 10-minute interactive page with a step-through loop demo.

Both are plain static HTML, with no build step.
